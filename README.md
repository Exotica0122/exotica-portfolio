# exotica-portfolio

Personal portfolio site built with [Astro](https://astro.build) and React, featuring a Hero, Skills, Projects, Experience, Certifications, and Contact section, plus a blog.

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                | Action                                           |
| :---------------------- | :----------------------------------------------- |
| `pnpm install`          | Installs dependencies                            |
| `pnpm dev`              | Starts local dev server at `localhost:4321`      |
| `pnpm build`            | Build your production site to `./dist/`          |
| `pnpm preview`          | Preview your build locally, before deploying     |
| `pnpm astro ...`        | Run CLI commands like `astro add`, `astro check` |
| `pnpm astro -- --help`  | Get help using the Astro CLI                     |

## 🛠 Stack

- [Astro](https://astro.build) with the [React integration](https://docs.astro.build/en/guides/framework-components/) for interactive components
- [Tailwind CSS v4](https://tailwindcss.com) via `@tailwindcss/vite`
- TypeScript
